# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability, please report it responsibly:

**Do NOT open a public issue.**

Instead, please email security reports privately or use [GitHub's private vulnerability reporting](https://github.com/Mohammed-Abdelaziem/hifz-trainer/security/advisories/new).

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond within 48 hours and work with you to understand and address the issue.

## Scope

This project handles:
- User authentication (email/password with scrypt)
- Session tokens (HTTP-only cookies)
- Supabase PostgreSQL database

We take data security seriously and will prioritize all security reports.
